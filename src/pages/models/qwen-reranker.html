Qwen3-Reranker

Open weights · Qwen, Alibaba · Updated 1 Oct 2026

Apache 2.0Instruction-awareGPU recommended

The Qwen3-Reranker family (0.6B / 4B / 8B) are Apache 2.0 rerankers built on Qwen3, with a 32K context, 100+ languages and support for a task instruction. In Qwen’s own tests the 4B and 8B lead bge-reranker-v2-m3 and gte-multilingual-reranker on every suite they ran — English, Chinese, multilingual, long-document and code. Those are Qwen’s numbers on Qwen’s setup: validate on your own labels before replacing bge or a hosted API.

All three: 32K context, 100+ languages, Apache 2.0.

For images, screenshots and video there is a separate family, Qwen3-VL-Reranker (2B / 8B, 32K context, 30+ languages, Apache 2.0). In Qwen’s own runs on ViDoRe v3, a visual-document retrieval benchmark, the 8B scores {{fact:qwen3-vl-reranker-8b.vidore_v3}} and the 2B {{fact:qwen3-vl-reranker-2b.vidore_v3}}; it is in the models table alongside LightOn-rerank, which also scores page images.

Recommendation: start with 4B on a single modern GPU. Drop to 0.6B only if memory is tight; move to 8B only when labelled eval shows a clear NDCG gain worth the cost.

Quick start

sentence-transformers

pip install sentence-transformers

from sentence_transformers import CrossEncoder

model = CrossEncoder("Qwen/Qwen3-Reranker-4B")

# Default instruction: "Given a web search query, retrieve relevant
# passages that answer the query" — override it per task:
model = CrossEncoder(
    "Qwen/Qwen3-Reranker-4B",
    prompts={"support": "Prefer official help articles with step-by-step instructions"},
    default_prompt_name="support",
)

ranked = model.rank(query, documents)   # [{"corpus_id": i, "score": s}, ...]

The model cards load the rerankers straight into sentence-transformers’ CrossEncoder. The card also shows a plain transformers path (transformers ≥ 4.51) that scores yes/no logits through Qwen’s chat template — get that template wrong and quality drops without an error.

In a RAG pipeline

# Pseudocode — same two-stage pattern as any cross-encoder
candidates = vector_db.search(query, top_k=80)   # or hybrid
scores = qwen3_rerank(query, candidates)         # official template
top = sorted(zip(scores, candidates), reverse=True)[:8]
answer = llm.complete(context=top, query=query)

When to pick Qwen3

  • Yes: you have GPU, need multilingual quality, and want open weights without per-call API cost.
  • Yes: long passages matter — all three take 32K tokens.
  • Yes: relevance needs steering. The rerankers take a task instruction; Qwen recommend writing one per task (in English, even for multilingual data) and report typical gains of 1–5%. See instruction-following rerank.
  • Maybe not: CPU-only or edge — prefer bge-v2-m3, mxbai, or Jina tiny for demos.

Pros and cons

Pros

  • Apache 2.0 at every size, 0.6B to 8B
  • 100+ languages and a 32K context
  • Takes a task instruction — the 4B has the best FollowIR score in Qwen’s table
  • Loads directly with sentence-transformers’ CrossEncoder
  • Zero per-call cost once self-hosted

Cons

  • GPU (or heavy quant) required for comfort
  • The raw transformers path needs Qwen’s exact prompt template
  • Vendor numbers are MTEB-R, not BEIR
  • Too large for our in-browser demo
