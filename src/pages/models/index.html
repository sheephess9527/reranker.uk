Rerank model comparison

Production stacks mix cross-encoders, listwise models, late-interaction, and instruction-following rerankers. The headline of 2026 is that size stopped predicting quality: a 0.6B listwise model (Jina v3.5) edges Qwen3-Reranker-4B on BEIR in Jina's own test, and in Qwen's own tests the 4B beats its 8B on English retrieval. Architecture, latency, languages and cost below — with honest footnotes wherever score protocols differ.

Tagged as a reranker, but not one for RAG: CLM-v0.1-8B from Contrastive-LM (September 2026) was the most-liked text-ranking model on Hugging Face by early October. It scores candidate actions and answers for agents — two small heads on a frozen Qwen3-8B, which you serve separately for its embeddings — and its headline results are agent benchmarks with fine-tuned heads, not retrieval. That is why it isn’t in this table.

How to choose

Open · GPU

Qwen3-Reranker

Best multilingual open weights — start at 4B

  • 0.6B / 4B / 8B, all Apache 2.0, all 32K context
  • 4B is the sweet spot — the 8B is twice the size for at most 1.5 points, and only outside English
  • Vendor numbers are MTEB-R, so verify on your own labelled set
Open · CPU

bge-reranker

Best free self-host when GPU is limited

  • Zero per-call cost — runs on your own infra
  • Strong multilingual quality (v2-m3 covers 100+ languages)
  • Drop-in with sentence-transformers, LangChain, LlamaIndex
API

Cohere Rerank 4

Easiest hosted API; pick Pro or Fast

  • Official SDK for Python, Node, Java, Go — one-liner integration
  • 32k context and 100+ languages on both variants
  • Pro for precision, Fast for throughput — ${{fact:cohere-rerank-4-pro.price_per_search}} vs ${{fact:cohere-rerank-4-fast.price_per_search}} a search
Open + API

Jina Reranker v3.5

Top-tier BEIR from a model that fits on one GPU

  • 63.20 BEIR nDCG@10 from 0.6B in Jina's own test — level with Qwen3-Reranker-4B, ~7× its size
  • Listwise: the query and all candidates share one 131K-token context
  • Weights are CC BY-NC 4.0: use the API, or license them for commercial self-hosting
API

Voyage rerank-3

Per-token pricing that tracks what you send

  • rerank-3 for accuracy, rerank-3-lite for latency — ${{fact:voyage-rerank-3.price_per_m_tokens}} and ${{fact:voyage-rerank-3-lite.price_per_m_tokens}} per 1M tokens
  • 200M free tokens per account on each; 32k context
  • Need the 33% Batch API discount? Voyage document it for the older rerank-2.5 only
Open

mxbai-rerank

Apache 2.0 open weights; v2 adds 100+ languages

  • Permissive Apache 2.0 licence — use commercially without restrictions
  • v1 xsmall variant runs in the browser (powers our live demo)
  • v2 (base/large) is multilingual, including Chinese — v1 was English-only
