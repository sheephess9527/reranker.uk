Why the ranking changes

Both vendors end up charging for text, but they round it differently. Cohere bills each candidate as one document per started {{fact:cohere-rerank.billing_chunk_tokens}} tokens — query included — and each search covers {{fact:cohere-rerank.docs_per_search}} documents. Voyage bills exactly the tokens you send, counting the query once per document.

At list prices the two meet exactly: {{fact:cohere-rerank.billing_chunk_tokens}} tokens costs the same on Cohere Rerank 4 Pro (${{fact:cohere-rerank-4-pro.price_per_search}} per search of {{fact:cohere-rerank.docs_per_search}} documents) and Voyage rerank-3 (${{fact:voyage-rerank-3.price_per_m_tokens}} per 1M tokens) — Voyage’s own pricing page uses that very example. What separates them is rounding:

  • Short passages — Cohere still bills each one as a full document, so per-token billing wins, by more the shorter they are.
  • Just past a {{fact:cohere-rerank.billing_chunk_tokens}}-token boundary — a 520-token candidate is two documents on Cohere; per-token billing costs about half.
  • Top-k that isn’t a multiple of {{fact:cohere-rerank.docs_per_search}} — Cohere rounds each query up to a whole search, so cost steps up rather than sliding.
  • Cohere Fast vs Voyage rerank-3 — Fast is cheaper only when query plus passage fills more than 80% of its last chunk. The -lite tier is cheaper than both on any workload.

Correction, October 2026: until now this page said Cohere’s {{fact:cohere-rerank.billing_chunk_tokens}}-token splitting was a myth and that per-search pricing ignores passage length. Cohere’s own pricing FAQ says otherwise: a document over {{fact:cohere-rerank.billing_chunk_tokens}} tokens, counting the query, is split, and every chunk counts toward the {{fact:cohere-rerank.docs_per_search}} documents in a search. The calculator now models that, which removes the long-passage advantage the old version showed for Cohere.

What about self-hosting?

Self-hosting has no per-call price, so it does not belong in the table above — you trade a usage bill for a GPU bill plus operations. The comparison only becomes meaningful at your own volume: divide your monthly GPU cost by the number of queries above and compare that to the per-query figures in the table. Below a few hundred thousand queries a month an API is usually cheaper than a dedicated GPU; well above that, self-hosting a Qwen3-Reranker or bge-reranker-v2-m3 starts to pay off. Our self-hosting guide covers the serving side.

Note that a smaller model is not automatically a worse one — Jina Reranker v3.5 reaches 63.20 BEIR nDCG@10 at 0.6B in Jina's own test, level with a 4B model, so the cheapest thing to serve may also be among the most accurate.

Assumptions and sources

  • Cohere Rerank 4 — ${{fact:cohere-rerank-4-pro.price_per_search}} per search (Pro) and ${{fact:cohere-rerank-4-fast.price_per_search}} per search (Fast). A search is one query plus up to {{fact:cohere-rerank.docs_per_search}} documents; per Cohere’s pricing FAQ, a document longer than {{fact:cohere-rerank.billing_chunk_tokens}} tokens including the query is split, and each chunk counts as a document. Prices are from cohere.com/pricing ($2.50 and $2 per 1,000 searches).
  • Voyage rerank-3 — ${{fact:voyage-rerank-3.price_per_m_tokens}} per 1M tokens, and ${{fact:voyage-rerank-3-lite.price_per_m_tokens}} for rerank-3-lite. Billable tokens are the query counted once per document, plus every document token you send — so 50 candidates means the query is billed 50 times. The older rerank-2.5 and -lite cost the same per token. Free tokens and the Batch API discount are not applied here — see the Voyage page for which models they cover.
  • Google Vertex AI ranking — ${{fact:vertex-ai-ranking.usd_per_1000_queries}} per 1,000 queries; a query covers up to 100 documents, and each further 100 counts as another query (Google’s pricing). Passage length doesn’t change the price, but the models read only 1,024 tokens per record.
  • Alibaba Cloud Model Studio — qwen3-rerank at ${{fact:alibaba-model-studio-rerank.qwen3_rerank_usd_per_m}} per 1M input tokens internationally and ¥{{fact:alibaba-model-studio-rerank.qwen3_rerank_cny_per_m}} in the Beijing region, where qwen3.7-text-rerank costs the same (price list). Alibaba bills input tokens and caps a request at query tokens × documents + document tokens, so this page counts tokens the way it does for Voyage. qwen3-rerank rejects any single document over 4,000 tokens rather than truncating it.
  • SiliconFlow — bge-reranker-v2-m3 is listed free and its Pro tier at ¥{{fact:siliconflow-rerank.bge_v2_m3_pro_cny_per_m}} per 1M tokens (price list). SiliconFlow doesn’t say how it counts rerank tokens; this page assumes the same formula as Alibaba and Voyage. Its price list gives no price for the Qwen3-Reranker models it also serves.
  • Token counts are approximate — every vendor tokenises differently, and this page multiplies your averages rather than tokenising real text.
  • Rates verified in October 2026 and re-checked daily against each vendor’s price page by this site’s source check. Confirm before committing to a budget.
