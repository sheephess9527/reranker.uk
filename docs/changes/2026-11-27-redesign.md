# 2026-11-27 — Site redesign: B4-3 / B1 dual themes, 5-act homepage, 2-column sticky TOC & direct tool access

## Scope and motivation

User requested a full visual and layout overhaul of `reranker.uk`, explicitly selecting the **B4-3 Royal Deep Sapphire (`#1e40af` / `#1e3a8a`) on Fog-White (`#f5f7fa` / `#ffffff`)** light theme paired with **B1 GitHub Dark Dimmed (`#1c2128` / `#22272e`)** night theme and an explicit **Auto** system-follow control.

All existing sourced benchmark numbers (`data/models.json`), pricing formulas (`public/assets/js/cost-calculator.js`), NDCG math (`public/assets/js/ndcg-calculator.js`) and demo scoring (`public/assets/js/demo.js`) were preserved unchanged.

## What changed

1. **Dual-theme palette & Auto system reset (`public/assets/css/style.css`, `src/partials/head-open.html`, `public/assets/js/main.js`, `public/assets/img/favicon.svg`, `public/site.webmanifest`)**
   - Replaced pitch-black (`#090b13`) + indigo/violet gradients (`#6366f1` → `#8b5cf6`) + rainbow `h1` text fill + ambient radial background glows with:
     - **Day (`html[data-theme="light"]`, B4-3)**: `#f5f7fa` canvas, `#ffffff` elevated cards, `#0f172a` ink, Royal Deep Sapphire `#1e40af` (`8.72:1` on white) primary accent, `#115e59` teal secondary.
     - **Night (`:root`, B1)**: `#1c2128` canvas, `#22272e` cards, `#e6edf3` ink, `#58a6ff` sky-blue primary, `#1f6feb` solid CTA button.
   - Added `#theme-auto` (`Auto` / `自动`) inside `.theme-group` in the header so readers who previously clicked the light/dark toggle can clear `localStorage["rr_theme"]` and resume following `prefers-color-scheme`.

2. **Header navigation, Search shortcut pill & 4-column footer (`src/partials/nav.html`, `src/partials/footer.html`, `src/i18n/shared.js`)**
   - Added direct top-nav links to **Picker** (`/reranker-picker`), **Cost** (`/rerank-cost-calculator`) and **News** (`/news`) alongside Home, Guides, Models and Live demo.
   - Styled `#search-toggle` as a labeled `⌕ Search /` (`⌕ 搜索 /`) pill on desktop and compact icon button on phones.
   - Split the 22-item single-column footer list into 4 balanced columns: Brand & quantized.uk LLM VRAM handoff, Guides (13), Tools & updates (10), and Models (12). Ensured inline links inside `.site-footer p` and `.footer-legal` carry explicit underlines for WCAG 1.4.1 (`link-in-text-block`).

3. **Balanced 5-act homepage (`src/pages/index.html`, `src/i18n/home.js`)**
   - **Act 1 (Split Hero)**: Left column holds core value + `Try the live demo` and `4-question picker →` actions; right column surfaces the two-stage retrieval pipeline diagram (`Query → Retriever 50–100 → Reranker top 5 → LLM`) above the fold instead of burying it at the bottom of the page.
   - **Act 2 (Interactive Tools Bench)**: 4-column equal-height row (`grid-4`) linking directly to Live demo, Reranker picker, Rerank cost calculator, and NDCG & MRR calculator.
   - **Act 3 & 4 (Reading Path + Job Shortcuts)**: Clean monospace step kickers (`Step 01..03`) replacing decorative emoji icons, plus direct link to `/guides/self-host-reranker`.
   - **Act 5 (Model Matrix + Vendor News Strip)**: 8 model family cards + 3-column `/news` strip highlighting recent vendor releases and deprecations (`pinecone-rerank-v0`, Cohere Rerank 5, NVIDIA Nemotron-3.5-Rerank-8B).

4. **Guides & Tools index (`src/pages/guides/index.html`, `src/i18n/guides-index.js`)**
   - Preserved the exact 5-guide `<ol class="grid grid-2 reading-path">` order used by `readingPathPager()` in `scripts/build.mjs`, added a dedicated 4-column **Interactive tools** section (surfacing Picker and NDCG calculator alongside Demo and Cost calculator), and removed decorative emojis.

5. **Two-column desktop Sticky TOC layout (`scripts/build.mjs`, `public/assets/css/style.css`)**
   - Added `applyDocLayout(root, zh)` in `scripts/build.mjs`: every `<article class="article">` with a `.toc` (all 25 guides and model reviews in EN and ZH) renders `.doc-grid` with a readable `.doc-prose` column (`max-width: 76ch`) and a sticky `.doc-aside` (`position: sticky; top: 82px`) on viewports `> 1020px`, automatically collapsing back to the inline `.toc` on tablets and phones.

6. **Interactive tool polish (`public/assets/css/style.css`)**
   - Styled `/reranker-picker` radio options (`.picker-opt`) as interactive selectable cards (`:has(input:checked)`) while keeping native radio inputs for full keyboard/screen-reader compatibility and zero-JS fallback.
   - Styled `.models-toolbar` as a clean card bar and enabled `font-variant-numeric: tabular-nums` across all tables and score readouts.

## Handoff notes

- Keep using CSS custom properties (`--bg`, `--bg-soft`, `--bg-card`, `--bg-elev`, `--border`, `--text`, `--text-soft`, `--primary`, `--primary-strong`, `--accent`) rather than hardcoded hexes so both **B4-3 Fog-White Royal Sapphire** and **B1 Dimmed Slate** stay WCAG AA compliant (`tests/a11y.spec.js` enforces contrast and `link-in-text-block` across all 72 pages).
- Any new guide or model review that includes `<div class="toc">` inside `<article class="article">` automatically receives the desktop two-column sticky TOC layout from `applyDocLayout()` in `scripts/build.mjs`.
