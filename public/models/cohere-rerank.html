    Cohere Rerank 5

    Hosted API · Cohere · Updated 22 Oct 2026

    Hosted APIMultilingualFree trial key

    Cohere Rerank was one of the first commercial reranking APIs and remains among the most widely deployed. The current generation, Rerank 5, was released on 21 October 2026 in two variants: rerank-v5.0-pro (about 2B parameters) for quality and rerank-v5.0-fast (about 500M) for throughput. Both take 32,768 tokens and 100+ languages, return calibrated scores, and can point to the passages that matter inside each document. Rerank 4 remains available.

    For new work, start with rerank-v5.0-pro, or rerank-v5.0-fast when throughput or tail latency matters more; Cohere say Rerank 5 Fast outperforms Rerank 4 Pro. Upgrading is a change to the model parameter: a reranker reads raw text at query time, so nothing needs re-indexing. Rerank 5 is billed per token, at $0.05 (Pro) or $0.02 (Fast) per million tokens, rather than per search like Rerank 4: see pricing.

    What’s new in Rerank 5

    • Calibrated scores. Each result’s score runs from 0 to 1 and is meant to mean the same thing across queries and domains, so one threshold can decide what reaches your LLM, or when to search again or answer “I don’t know”. Check any threshold tuned on Rerank 4 before reusing it.
    • Context Focus. Optional, and off by default. Add relevant_spans to the request and each result also returns the passages inside the document that answer the query, as scored character offsets, so you can send only those to your LLM or highlight them for users.
    • Semi-structured data. Pass JSON, tables or records as YAML strings.
    "relevant_spans": {"mode": "enabled", "threshold": 0.3, "max_spans": 10}

    A higher threshold keeps less text, and max_spans caps the passages per document. Cohere note that Context Focus suits targeted questions; summarisation needs the whole document, and tables, forms and code split less cleanly than prose. It is available through Cohere’s own API.

    What it doesn’t do: Rerank 5 takes text only, and it doesn’t accept instructions that change how relevance is judged. For that, see instruction-following rerankers such as Voyage rerank-3 or Qwen3-Reranker.

    Where it runs: the Cohere API, Cohere’s Model Vault, Microsoft Foundry and Amazon SageMaker, or a private deployment. Amazon Bedrock’s rerank API still lists only Rerank 3.5.

    Quick start

    Python

    pip install cohere
    import cohere

co = cohere.ClientV2("YOUR_API_KEY")

query = "How do I add reranking to my RAG pipeline?"
documents = [
    "Rerankers score each query-passage pair jointly with a cross-encoder.",
    "BM25 is a classical keyword-based retrieval method.",
    "London is the capital of the United Kingdom.",
    "Two-stage retrieval: retrieve 50 candidates, rerank to top 5.",
]

results = co.rerank(
    model="rerank-v5.0-pro",
    query=query,
    documents=documents,
    top_n=3,
)

for r in results.results:
    print(f"{r.relevance_score:.4f}  {documents[r.index][:80]}")

    Node.js

    import Cohere from "cohere-ai";
const co = new Cohere.Client({ token: "YOUR_API_KEY" });

const result = await co.rerank({
  model: "rerank-v5.0-pro",
  query: "How do I add reranking to my RAG pipeline?",
  documents: ["...", "..."],
  topN: 3,
});

result.results.forEach((r) => console.log(r.relevanceScore, documents[r.index]));

    REST (curl)

    curl https://api.cohere.com/v2/rerank \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rerank-v5.0-pro",
    "query": "How do I add reranking to my RAG pipeline?",
    "documents": ["Rerankers score query-passage pairs...", "BM25 is..."],
    "top_n": 3
  }'

    Pros and cons

    Pros

    • Mature, production-grade API with an SLA
    • Consistent quality across 100+ languages
    • SDK support: Python, Node, Java, Go, curl
    • Free trial key for prototyping (1,000 calls a month)
    • 32,768-token context window
    • Rerank 5: calibrated scores and Context Focus
    • Rerank 5 bills per token, so short passages cost less

    Cons

    • Closed weights — you depend on Cohere
    • Rerank 4’s per-search billing counts passages over 500 tokens as several documents
    • Self-hosting means a private-deployment contract
    • No task instructions, even in Rerank 5
    • Every call is a network round trip — measure from your own region
