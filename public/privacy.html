    Privacy

    reranker.uk is a static educational site. Here is what happens to your data when you browse or use the live demo.

    Static pages

    Guide and model pages are plain HTML served from Cloudflare. There are no ads, tracking pixels, or sign-in flows on this site.

    Analytics

    We use Cloudflare Web Analytics to count page views and see how quickly pages load. Cloudflare adds a small script to each page, which measures load times with your browser’s Performance API and reports them to this site’s own address.

    According to Cloudflare’s documentation, it sets no cookies and uses no local storage, does not fingerprint visitors by IP address or user agent, does not collect visitors’ personal data, and does not record query strings — so the text in a demo share link is not part of it. Ad blockers often block the script; the site works the same either way.

    Live demo

    The reranking demo runs entirely in your browser with transformers.js. Your query and candidate passages are processed locally on your device. They are not sent to reranker.uk servers or any rerank API.

    On first use, the demo downloads open-weight model files from the Hugging Face CDN (via jsDelivr). Those weights are cached in your browser storage for faster repeat visits. Share links encode your query and passages in the URL — only share them with people you trust, since anyone with the link can read that text.

    Third parties

    • Cloudflare — hosts static files, may log standard request metadata (IP, user agent) per their privacy policy, and runs the analytics described above.
    • jsDelivr / Hugging Face — serves transformers.js and ONNX model weights when you open the demo.
    • GitHub — if you follow the “View source” link, GitHub’s terms apply.

    Contact

    Questions or corrections: open an issue on GitHub.
