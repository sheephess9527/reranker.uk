    Reranking in mainland China: Alibaba Cloud, SiliconFlow or your own server

    Practical · ~8 min read · Updated 14 Oct 2026

    From a server in mainland China, the usual advice — call Cohere or Voyage, or download weights from Hugging Face — runs into slow or blocked connections and foreign-currency billing. There are three routes that work well from inside China: Alibaba Cloud Model Studio, SiliconFlow, or running an open model yourself. This guide compares them on price, Chinese-language quality and setup, using only what each vendor publishes.

    Three routes at a glance

    RouteModelsPricePick it when
    Alibaba Cloud Model Studio qwen3-rerank, qwen3.7-text-rerank, qwen3-vl-rerank (images and video) ¥0.5 per million input tokens You already use Alibaba Cloud, need long documents or many languages, and don’t want to run a GPU
    SiliconFlow Hosted open models: bge-reranker-v2-m3, bce-reranker-base_v1, Qwen3-Reranker 0.6B / 4B / 8B, Qwen3-VL-Reranker-8B bge-reranker-v2-m3 free; Pro tier ¥0.07 per million tokens You want an open model without hosting it, or a free tier to start on
    Your own server bge-reranker-v2-m3 (CPU), Qwen3-Reranker-4B (GPU), gte-multilingual-reranker-base No per-call price; you pay for the hardware Data must not leave your network, or your volume is high enough that a GPU costs less than an API

    The three are not exclusive. A common path is to start on SiliconFlow’s free bge-reranker-v2-m3, measure on your own queries, then either stay hosted or move the same open model onto your own hardware — the scores don’t change, because it is the same model.

    How well the models handle Chinese

    The one public comparison that covers most of these models on Chinese retrieval is Qwen’s: CMTEB-R, the retrieval tasks of the Chinese MTEB, reranking the top 100 from Qwen3-Embedding-0.6B. It is Qwen’s own run, so read it as a guide to tiers rather than a final ranking.

    ModelSizeCMTEB-RMMTEB-R (multilingual)
    bge-reranker-v2-m3568M72.1658.36
    gte-multilingual-reranker-base306M74.0859.44
    Qwen3-Reranker-0.6B0.6B71.3166.36
    Qwen3-Reranker-4B4B75.9472.74
    Qwen3-Reranker-8B8B77.4572.94

    From the Qwen3-Reranker model card, checked daily. Alibaba Cloud publishes no scores for its hosted qwen3-rerank, qwen3.7-text-rerank or qwen3-vl-rerank, so they are not in the table.

    Two things stand out. The 306M gte-multilingual-reranker-base scores above bge-reranker-v2-m3 on Chinese at about half its size, which makes it the cheapest model to serve here. And the step from bge-reranker-v2-m3 to Qwen3-Reranker-4B is small on Chinese but large on the multilingual column — worth it if your corpus mixes languages, less so for Chinese alone. The classic English models (ms-marco MiniLM, Jina v1, mxbai v1) were not trained on Chinese and don’t belong in this list.

    Alibaba Cloud Model Studio

    Model Studio (百炼) sells three rerankers, billed per million input tokens in yuan in the Beijing region:

    • qwen3-rerank — 100+ languages, up to 500 documents per request and 4,000 tokens per document. A longer document is rejected with an error, not truncated, so chunk before you send.
    • qwen3.7-text-rerank — 201 languages and dialects and up to 30,000 tokens per document, at the same price; Beijing region only.
    • qwen3-vl-rerank — ranks images and video as well as text.

    All three take an instruct parameter that says what “relevant” means; without one they rank for question answering, and Alibaba suggest writing instructions in English (see instruction-following rerankers). The older gte-rerank was retired on 30 May 2026; gte-rerank-v2 is still sold. qwen3-rerank is also offered internationally at $0.1 per million tokens.

    # From Alibaba Cloud's Model Studio docs (qwen3-rerank)
curl --request POST \
  --url https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-api/v1/reranks \
  --header "Authorization: Bearer $DASHSCOPE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "qwen3-rerank",
    "query": "什么是文本排序模型",
    "documents": [
      "文本排序模型广泛用于搜索引擎和推荐系统中，它们根据文本相关性对候选文本进行排序",
      "量子计算是计算科学的一个前沿领域",
      "预训练语言模型的发展给文本排序模型带来了新的进展"
    ],
    "top_n": 2
  }'

    qwen3.7-text-rerank, qwen3-vl-rerank and gte-rerank-v2 use a different endpoint and request shape; the Model Studio rerank API page has both.

    SiliconFlow

    SiliconFlow (硅基流动) runs other vendors’ open models behind one rerank endpoint, so what you call is the published open model, and the table above describes it. Its price list shows bge-reranker-v2-m3 as free and a Pro tier at ¥0.07 per million tokens; it lists no price for the Qwen3-Reranker models.

    import requests

resp = requests.post(
    "https://api.siliconflow.cn/v1/rerank",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "model": "BAAI/bge-reranker-v2-m3",
        "query": "如何退货",
        "documents": ["退货需在收货后七天内申请", "我们的门店营业时间为早九点到晚九点"],
        "top_n": 1,
    },
).json()

for r in resp["results"]:
    print(r["index"], r["relevance_score"])

    Two options are model-specific. instruction works only with the Qwen3-Reranker models. For bge-reranker-v2-m3 and bce-reranker-base_v1, SiliconFlow splits a long document into chunks itself (max_chunks_per_doc, overlap_tokens) and scores the document by its best chunk — convenient, but it means a long document wins on its single best passage. Qwen3-VL-Reranker-8B has its own multimodal request format. Details are on the SiliconFlow rerank API page.

    Self-hosting: getting the weights

    The models are open, but huggingface.co is often slow or unreachable from mainland China. Two ways around it:

    • hf-mirror.com, a community mirror of Hugging Face. Set HF_ENDPOINT and every tool built on huggingface_hub — including sentence-transformers — downloads from the mirror.
    • ModelScope (魔搭), Alibaba’s model hub, which hosts Qwen/Qwen3-Reranker-4B and BAAI/bge-reranker-v2-m3 under the same names.
    # Linux / macOS — from hf-mirror.com's own instructions
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download BAAI/bge-reranker-v2-m3 --local-dir bge-reranker-v2-m3

# With HF_ENDPOINT set, sentence-transformers fetches from the mirror too
python -c "from sentence_transformers import CrossEncoder; CrossEncoder('BAAI/bge-reranker-v2-m3')"

    From there, serving is the same as anywhere else — see self-hosting a reranker. bge-reranker-v2-m3 runs on a CPU; Qwen3-Reranker-4B wants a GPU. Our browser demo uses the mirror too: it requests the model from huggingface.co and hf-mirror.com at once and keeps whichever answers first.

    What it costs

    Alibaba Cloud and SiliconFlow both bill by the token, so the cost scales with how many candidates you rerank and how long they are, not with the number of queries alone. The cost calculator’s yuan table works it out for your volume, and warns when your passages are longer than qwen3-rerank accepts. Free quotas and trial credits are not included; check each vendor’s price page.

    Whichever route you pick, label 30–100 of your own queries and compare before committing — the evaluation guide shows how.
