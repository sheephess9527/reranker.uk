    See the full comparison →

    Qwen3-Reranker

    0.6B / 4B / 8B Apache 2.0 family — the multilingual GPU self-host pick. Start at 4B, not 8B.

    Open weightsMultilingual

    bge-reranker

    Open-weight rerankers from BAAI. Still the best CPU-friendly multilingual default.

    Open weightsSelf-host

    Cohere Rerank 5

    Mature hosted API, new generation on 21 October 2026: Pro and Fast, 32k context, 100+ languages, calibrated scores and Context Focus.

    Hosted APIMultilingual

    Jina Reranker v3.5

    Jina reports 63.20* BEIR nDCG@10 for this 0.6B listwise model. Weights are non-commercial; v1-tiny powers our demo.

    Hosted APIListwise

    Voyage rerank-3

    Hosted rerankers you steer with a natural-language instruction. 32k context, per-token pricing.

    Hosted APIInstruction

    mxbai-rerank

    Apache 2.0 open weights. v1's xsmall runs in the browser; v2 adds 100+ languages, including Chinese.

    Open weightsBrowser ✓

    zerank-2

    ZeroEntropy’s 4B reranker, Apache 2.0 weights on Hugging Face. Its hosted API closed in September 2026, when the team joined Notion.

    Open weightsAPI closed

    Qwen3-VL-Reranker

    Reranks page images, screenshots and video, not just text. 2B and 8B, Apache 2.0.
