隐私说明

reranker.uk 是静态教育站点。浏览或使用在线 Demo 时，你的数据会经历以下处理。

静态页面

指南与模型页为 Cloudflare 提供的纯 HTML。本站不运行第一方分析、追踪像素或登录流程。

在线 Demo

重排序 Demo 完全在浏览器内通过 transformers.js 运行。查询与候选段落在你的设备本地处理，不会发送到 reranker.uk 服务器或任何 rerank API。

首次使用时，Demo 从 Hugging Face CDN（经 jsDelivr）下载开源模型文件，权重会缓存在浏览器存储中以加速再次访问。分享链接把查询与段落编码进 URL —— 只发给信任的人，持有链接者均可阅读其中文本。

第三方

  • Cloudflare —— 托管静态文件，可能按其 隐私政策 记录常规请求元数据（IP、User-Agent）。
  • jsDelivr / Hugging Face —— 打开 Demo 时提供 transformers.js 与 ONNX 模型权重。
  • GitHub —— 若点击「查看源码」链接，适用 GitHub 条款。

联系

问题或勘误：在 GitHub 提交 issue。
