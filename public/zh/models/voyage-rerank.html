Voyage rerank-3

托管 API · Voyage AI · 更新于 2026 年 10 月 1 日

托管 API按 token 计费32K 上下文

Voyage AI 当前的重排序模型是 rerank-3 —— Voyage 称之为准确度最高、推荐大多数应用使用的模型 —— 以及为延迟优化的 rerank-3-lite。两者都支持 query 加文档共 32,000 token，都按 token 计费，每个账号各送 200 million 免费 token。上一代 rerank-2.5 仍以相同价格提供 —— 而且 Voyage 文档里写明支持自然语言指令和 Batch API 的，正是它。

可用模型

模型上下文说明
rerank-332,000 tokens准确度最高；Voyage 推荐大多数应用使用
rerank-3-lite32,000 tokens快速、经济，适合对延迟敏感的场景
rerank-2.5 / rerank-2.5-lite32,000 tokens旧版；Voyage 文档写明支持指令与多语言
rerank-2 / rerank-2-lite16,000 / 8,000 tokens旧版

每次请求：query 最多 8,000 token，query 加任一篇文档最多 32,000 token，文档最多 1,000 篇，总量最多 60 万 token —— query 按每篇文档各算一次。

指令 —— 例如在 query 里加一句「优先选择引用了法条的段落」 —— 无需训练数据就能改变相关性判断。Voyage 的文档只为 rerank-2.5 及其 -lite 介绍了指令用法，没有说 rerank-3 是否支持；如果你依赖指令，切换前请先测试。

价格

模型每百万 token免费 token
rerank-3$0.05200 million
rerank-3-lite$0.02200 million
rerank-2.5 / -lite$0.05 / $0.02无
Batch API减 33%rerank-2.5 及其 -lite；不可使用免费 token

计费 token = query token × 文档数 + 全部文档 token。按标价，100 篇各 500 token（含 query）的文档在 rerank-3 上花费 $0.0025 —— 这是 Voyage 自己举的例子，恰好等于 Cohere Rerank 4 Pro 一次检索的价格。Voyage 价格页里仍有一句话说 rerank-2.5 含免费 token，但同一页的价格表把 rerank-2.5 列在不送免费 token 的旧模型里；我们以价格表为准。价格取自 docs.voyageai.com/docs/pricing，2026 年 10 月 1 日核对，本站来源检查每天复核。

快速上手

Python

pip install voyageai
import voyageai

vo = voyageai.Client(api_key="YOUR_API_KEY")

query = "How do I add reranking to my RAG pipeline?"
documents = [
    "Rerankers score each query-passage pair with a cross-encoder.",
    "BM25 is a classical keyword-based retrieval method.",
    "London is the capital of the United Kingdom.",
    "Two-stage retrieval: retrieve 50 candidates, rerank to top 5.",
]

result = vo.rerank(
    query=query,
    documents=documents,
    model="rerank-3",
    top_k=3,
)

for r in result.results:
    print(f"{r.relevance_score:.4f}  {documents[r.index][:80]}")

REST（curl）

curl https://api.voyageai.com/v1/rerank \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "rerank-3",
    "query": "How do I add reranking to my RAG pipeline?",
    "documents": ["Rerankers score...", "BM25 is..."],
    "top_k": 3
  }'

在 RAG 流水线中

import voyageai

vo = voyageai.Client(api_key="YOUR_API_KEY")

def rag_answer(query: str, vector_db, llm) -> str:
    # Stage 1: retrieve wide
    candidates = vector_db.search(query, top_k=50)
    # Stage 2: rerank tight
    result = vo.rerank(query=query, documents=candidates, model="rerank-3", top_k=5)
    top5 = [candidates[r.index] for r in result.results]
    # Stage 3: generate
    return llm.complete(f"Context:\n" + "\n\n".join(top5) + f"\n\nQ: {query}")

优缺点

优点

  • rerank-3：Voyage 准确度最高的重排序模型，每对 query–文档 32K token
  • 只按你实际发送的 token 计费 —— 段落短时很便宜
  • rerank-3 和 -lite 每个账号各送 200 million 免费 token
  • 与 Voyage 向量模型共用同一个 API key 和客户端
  • 提供 Python 与 TypeScript 库，以及 REST 接口

缺点

  • 没有开源权重；私有部署需通过 AWS 或 Azure 应用市场
  • 指令与 Batch 折扣目前只在旧版 rerank-2.5 的文档中写明
  • 没有公布 BEIR 均值 —— 只能依据 Voyage 自己的评测来比较
  • 社区规模小于 Cohere 或 bge
