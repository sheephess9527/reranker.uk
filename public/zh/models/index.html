Qwen3-Reranker

Open weights2026 SOTA*

0.6B / 4B / 8B 家族 —— 2026 多语言 GPU 自建开源主线。质量优先从 4B 起。

bge-reranker

Open weightsSelf-host

智源开源权重。仍是 CPU 友好默认（v2-m3）。有 GPU 余量时与 Qwen3 对比。

Cohere Rerank

Hosted API多语言

最成熟的托管重排序 API，多语言质量稳定，免费额度慷慨，并提供 Python、Node、Java、Go 的 SDK。

Jina Reranker

Open + Hostedv3 listwise

v3 listwise 长上下文旗舰；v1-tiny 仍驱动 Demo。开源 + 托管 API。

Voyage Rerank

Hosted APIDomain-specific

Voyage AI 的重排序器专门为检索精度优化，并为代码和金融提供领域调优的变体。

mxbai-rerank

Open weightsBrowser xsmall

Apache 2.0 DeBERTa-v3 rerankers from mixedbread-ai. The xsmall variant runs in the browser and powers our demo.

如何选择

Open · GPU

Qwen3-Reranker

2026 开源 SOTA 候选 —— 从 4B 起步

  • 0.6B / 4B / 8B —— 按 GPU 在体量与延迟间取舍
  • 多语言 + 长上下文（MTEB-R 报道）
  • Apache 2.0 家族；用自有标注验证
Open · CPU

bge-reranker

GPU 有限时的最佳免费自建

  • 零按次成本 —— 跑在你自己的基础设施上
  • 强多语言质量（v2-m3 覆盖 100+ 种语言）
  • 与 sentence-transformers、LangChain、LlamaIndex 即插即用
API

Cohere Rerank

最简单的托管 API，顶级多语言质量

  • Python、Node、Java、Go 官方 SDK —— 一行代码接入
  • 100+ 语言的稳定多语言质量
  • 慷慨的免费额度；成熟、久经生产验证的 API
Open + API

Jina Reranker

v3 listwise + 浏览器 tiny

  • v3 listwise 长上下文，适合生产排序
  • v1-tiny 仍可在浏览器跑（本站 Demo）
  • 免费档；开源权重 + 托管 API
API

Voyage Rerank

顶级检索精度，领域专用变体

  • 专门为检索质量调优，而非仅面向分类任务
  • 面向代码搜索和金融的领域专属模型
  • 托管 API 中按千条计费最低价
Open

mxbai-rerank

Apache 2.0 开源权重，浏览器可运行的 xsmall

  • 宽松的 Apache 2.0 协议 —— 可商用、无限制
  • xsmall 变体可在浏览器中运行（驱动本站实时 Demo）
  • 大参数版本在本表中 BEIR 分数最高
