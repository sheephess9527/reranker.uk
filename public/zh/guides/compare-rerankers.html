    2026 年最好的 reranker：Qwen3、bge、mxbai、Jina、GTE 和托管 API 横向对比

    横向对比 · 约 7 分钟阅读 · 更新于 2026 年 11 月 10 日

    每家 reranker 厂商公布的表格里，赢的都是自己的模型，而且各家用的数据集不同，数字没法跨厂商直接对齐。本页只在分数来自同一次评测时才把它们并排放，并写明是谁跑的；没有可比数字的模型，也会直接说明。

    先说结论

    • 自托管、有 GPU、想要最好的开源模型：Qwen3-Reranker-4B。下面两次评测里它都在榜首或接近榜首，而且是 Apache 2.0 协议。
    • 要小、能在 CPU 上跑、支持多语言：bge-reranker-v2-m3 是通行的基线；GTE reranker 还要更小，Hindsight 的 hs-rerank-1（MIT，114M）更小，但没有可以引用的分数。
    • 没有 GPU，也不想运维：用托管 API。Cohere Rerank 5 和 Voyage rerank-3 是老牌选择，zerank-2 按 token 算最便宜。
    • 商用产品、想用开源权重：先看许可证。Jina 的权重是非商用的。

    哪些数字能比

    分数只有和同一次评测里的分数放在一起才有意义：同样的数据集、同一个第一阶段检索器给出的同样的候选列表、同样的截断位置。两家厂商页面上的数字不在同一把尺子上，哪怕两边都写着“nDCG@10”或“BEIR”。本页用的两次评测都一次覆盖了好几个模型，但两次都是由表里有自家模型的厂商来跑的，所以只能当作有力的线索，最终还要在你自己标注的查询上验证（怎么做）。

    有三类模型没有可放进来的评测。GTE：阿里只以图表形式公布 reranker 结果，没有可以对齐的表格。Cohere：Rerank 5 没有公布过评测表。hs-rerank-1：Hindsight 的模型卡只以图片形式展示结果。下面改从规模、许可证、价格和适用场景来比较它们。

    Qwen3 对比 bge-reranker-v2-m3

    这是 Qwen 自己跑的评测，来自 Qwen3-Reranker 的模型卡：MTEB 的检索子集（英文、中文、多语言和代码）以及用于长文档的 MLDR，每项都对同一批前 100 个候选重排。

    模型MTEB-RCMTEB-RMMTEB-RMLDRMTEB-Code
    Qwen3-Reranker-8B69.02*77.4572.9470.1981.22
    Qwen3-Reranker-4B69.76*75.9472.7469.9781.20
    Qwen3-Reranker-0.6B65.80*71.3166.3667.2873.42
    bge-reranker-v2-m357.0372.1658.3659.5141.38

    4B 和 8B 在每一列上都领先 bge-reranker-v2-m3，差距最大的是代码。如果你做中文，0.6B 是需要留意的例外：它在 CMTEB-R 上是 71.31，而 bge 是 72.16，缩到 0.6B 就丢掉了中文上的领先。8B 也不比 4B 明显更好：只有中文上领先，多语言、长文档和代码基本持平，英文上反而落后。

    同一次 BEIR 评测里的 Qwen3、mxbai 和 Jina

    这是 Jina 的 2026 年评测，来自 jina-reranker-v3.5 的模型卡。Jina 在同一套协议下重跑了六个模型（nDCG@10）：13 个 BEIR 数据集、用于多语言检索的 MIRACL、用于专业领域（法律、金融、代码、医学）的 RTEB，以及用于结构化数据的 Struct-IR，每项都对 jina-embeddings-v5-text-small 给出的前 100 个候选重排。下表列出其中四个；这次评测里没有 bge-reranker-v2-m3。

    模型BEIRMIRACLRTEBStruct-IR
    jina-reranker-v3.5（0.6B）63.2074.1170.9548.3
    mxbai-rerank-large-v2（1.5B）62.4569.6570.8143.0
    Qwen3-Reranker-4B62.2876.5677.6855.6
    Qwen3-Reranker-0.6B56.9467.1268.4141.9

    在纯英文的 BEIR 上，前三名相差不到一分，这个基准分不出高下。差别出现在别处：Qwen3-Reranker-4B 在多语言、专业领域和结构化检索上领先得很明显。Jina 自家的模型在 Jina 自己的评测里拿下 BEIR 第一；它的权重是非商用的，所以做产品时实际要比的是 Qwen3 和 mxbai。

    托管 API

    按 token 付费，不用自己养 GPU。这几家都没有公布可比的评测，所以表里只列能核对的：价格和上下文长度。

    API每百万 token 价格上下文评测
    Cohere Rerank 5 Pro / Fast$0.05 / $0.0232,768 token未公布
    Voyage rerank-3 / lite$0.05 / $0.0232,000 token仅有 Voyage 自己的评测
    zerank-2$0.02532,768 token仅有 ZeroEntropy 自己的评测

    按 token 计费和按次计费的算法不同，所以标价最低的不一定账单最低。成本计算器可以按你每次查询的文档数和每月查询量算出来。

    怎么选

    1. 先从本页挑两个候选：一个你能自己部署的开源模型，一个托管 API。
    2. 标注 30–50 条真实查询：取自你自己的用户，并标出能回答它们的段落。
    3. 两个都跑一遍，比较 nDCG@10，用你的标注和同一份候选列表。这是唯一能预测你实际效果的比较；评测指南里有完整步骤。
    4. 确认瓶颈真的是重排序。如果正确的段落根本没进候选，换什么 reranker 都没用；见为什么重排序没起作用。
