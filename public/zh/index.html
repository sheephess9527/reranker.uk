Reranker · rerank 模型 · 为 RAG 重排序

读懂 reranker，再亲眼看它在你的浏览器里运行。

重排序器（reranker）会对检索得到的候选重新打分，让最相关的段落浮到最前面。在这里了解它的原理、对比主流模型，并实时体验一个 cross-encoder —— 零 API 成本，数据全程不离开你的设备。

两阶段检索范式、排序为何重要，以及重排序在其中的位置。

Cross-encoder vs bi-encoder

为什么 bi-encoder 快、cross-encoder 准，以及如何把两者结合使用。

bi-encoder 负责大规模召回，cross-encoder 负责精准排序。把它们组合成两个阶段来使用。

如何为 RAG 加重排序

宽召回、重排序、保留最优。含代码、top-k 取值建议与延迟取舍。

召回 50+ 个候选，重排序，保留 5 个 —— 更好的答案，更少的 token 送进 LLM。

对比主流重排序模型

2026 开源 SOTA 候选（Qwen3-Reranker）、Jina v3.5 listwise、经典 bge/mxbai、托管 Cohere/Voyage —— 以及 late-interaction 与指令 API。

Qwen3-Reranker

0.6B / 4B / 8B 的 Apache 2.0 家族 —— 多语言 GPU 自托管首选。从 4B 起步，而不是 8B。

开源权重多语言

bge-reranker

智源（BAAI）开源权重。仍是 CPU 友好的多语言默认。

开源权重自建部署

Cohere Rerank 4

成熟的托管 API，分 Pro 与 Fast 两档 —— 32k 上下文、100+ 语言，按「次检索」计费。

托管 API多语言

Jina Reranker v3.5

0.6B 的 listwise 模型，在 Jina 自己的测试里 BEIR 达 63.20*，与 Qwen3-Reranker-4B 持平。权重仅限非商用；v1-tiny 仍在驱动我们的 Demo。

托管 APIListwise

Voyage rerank-3

可以用自然语言指令来引导的托管重排序器。32k 上下文，按 token 计费。

托管 APIInstruction

mxbai-rerank

Apache 2.0 开源权重。v1 的 xsmall 可在浏览器运行；v2 新增 100+ 种语言支持，包括中文。

开源权重浏览器 ✓
